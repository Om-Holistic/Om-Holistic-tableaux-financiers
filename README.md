# Om Holistic — Tableau de bord financier

Reconstruction du simulateur financier Chrysalis. Application statique sans serveur ni Vercel. Ouvrir index.html ou activer GitHub Pages sur main / racine.

Hypothèses de simulation, pas de données observées. Acquisition hebdomadaire bornée, paliers personnalisables, bêta, lancement, promotions, capacité et liste d'attente, abonnements directs et après programme, durée moyenne et résiliation mensuelle 1/durée. Les paramètres sont locaux au navigateur ; exporter régulièrement le JSON. Les anciennes sauvegardes Chrysalis Pilot ne sont pas directement compatibles. Les charges sont une hypothèse mensuelle globale, pas une comptabilité complète.
